# MEMORYOS System Architecture

## 1. Overview
MEMORYOS is an intelligent, production-oriented conversational memory engine designed to extract, store, update, and retrieve contextual facts across multi-turn, multilingual interactions with complete character isolation and temporal awareness.

## 2. Core Subsystems

### 2.1 Security & Multi-Tenant Isolation
- Every database entity links to `owner_user_id` and `character_id`.
- The API dependency extracts and verifies the authenticated `Principal` from JWT.
- All SQL queries explicitly include `WHERE owner_user_id = :user_id AND character_id = :char_id`.
- Foreign entity lookups return HTTP 404/403 with identical response structures to eliminate information leakage.

### 2.2 Neural Extraction Engine
- Handles English and Romanized Hinglish seamlessly.
- Categorizes statements into normalized subject-predicate-object tuples.
- Flags polarity (positive vs. negative preferences, e.g. "Mujhe coffee pasand nahi hai").
- Distinguishes user assertions from questions or hypothetical musings.

### 2.3 Memory Lifecycle & Temporal Reasoning
- Tracks historical changes across time (e.g. "Lived in Indore" -> "Moved to Pune").
- Updates existing records with `valid_until` timestamps and maintains `supersedes_memory_id` lineage.
- Atomic commits ensure partial failures never leave broken provenance graphs.

### 2.4 Hybrid RAG Retrieval Engine
- **Lane A (Structured)**: Exact relational filters on domain, predicate, and temporal status (`current` vs `historical`).
- **Lane B (Lexical)**: PostgreSQL `to_tsvector` and `ts_rank` matching natural query terms and transliterations.
- **Lane C (Dense Semantic)**: Cosine distance (`<=>`) using pgvector with 384-dimensional dense vectors generated by ONNX-powered `BAAI/bge-small-en-v1.5` / `all-MiniLM-L6-v2`.
- **Fusion & Reranking**: Reciprocal Rank Fusion ($RRF = \sum \frac{1}{k + rank_i}$) harmonizes ranks, followed by a temporal and confidence reranker.
